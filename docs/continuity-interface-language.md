# Bilingual continuity controls on the integrated PerPulse candidate

This slice follows [#20](https://github.com/Lightmaze/Per-Pulse/pull/20) with one native World, Kernel and ContextPulseController. Reuses the typed i18n preference/catalogues already developed in [#9](https://github.com/Lightmaze/Per-Pulse/pull/9), not a parallel locale mechanism.

The independent **interface language** setting follows the browser or an explicit English/简体中文 choice, syncs across tabs and updates document.lang without remounting Home/Work. **Reply language** remains a separate World-owned next-turn setting. Switching controls never approves tools or touches history. The translated vertical slice includes the Home heading/navigation, Activity including holds/connections and original causal event labels, Settings, exact Harness approvals and digest-checked file result status. Work titles, human messages, filenames, trace/event IDs, and raw runtime failure details remain verbatim.

The integrated Learning dialog also provides English and Simplified Chinese controls for inspecting, refining and reporting lessons, selecting an optional completed result, and following its source. Switching the interface language preserves an unsent report and its selected result; a known revision-conflict error follows the new language without retrying the write. Original lesson and result content remain verbatim. This is coverage of these workflows, not a claim that all auxiliary dialogs and runtime diagnostics are translated. See [the attributed lesson workflow](posture-engineering-next.md#link-a-report-to-the-actual-completed-result).

Verification: `npm --prefix web ci && npm --prefix web run test && npm --prefix web run typecheck && npm --prefix web run build`, the unified Python/Chromium CI, then a browser flow that switches locale while preserving an unsent Work draft, original-source anchor, pending approval and file digest. Synthetic HTTP transport does not establish provider performance.
