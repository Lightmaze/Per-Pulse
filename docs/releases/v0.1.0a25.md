# Per Pulse v0.1.0a25

Keep the exact source materials and earlier user decisions with the right task when continuing across Home and Work. This alpha packages three already-merged improvements after [v0.1.0a24](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a24).

## Continue with the right input and source

- **Drop a file together with text.** Dragging supported image material alongside a plain-text note into Home or Work preserves both in the same unsent draft, even after refreshing or leaving and returning to the Work. The message is sent only when you choose Send ([#294](https://github.com/Lightmaze/Per-Pulse/pull/294)).
- **Keep earlier user corrections recognizable in a long conversation.** When older user messages leave the model request's context window, up to two recent omitted messages can appear as short, explicitly historical excerpts with their original `message_id` and a `read_history` path. The original transcript and action authorization remain unchanged ([#295](https://github.com/Lightmaze/Per-Pulse/pull/295)).
- **Start the next message without resending old attachments.** If you edit a new draft while an earlier message containing source materials is still being sent, a confirmed Send removes only those already-sent material IDs. New text and newly attached materials stay with the new draft; an unsuccessful Send preserves the existing recovery path ([#296](https://github.com/Lightmaze/Per-Pulse/pull/296)).

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a25-py3-none-any.whl` from this release after publication.

Linux or macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a25-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a25-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example runs without a configured model. Stop the application and back up your complete data directory before upgrading a real workspace. See the [installation guide](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/install.md).

## Verification and boundaries

The release candidate requires Native, Chromium, Windows and Docker CI, package and source-archive verification, and cold installation on Linux, Windows and macOS. The merge commit then needs independent main CI before the release workflow publishes the tag, wheel, sdist and SHA256SUMS. Automated browser model calls are scripted fixtures; real-model adoption of an older correction across Works still requires separately authorized provider testing under [#51](https://github.com/Lightmaze/Per-Pulse/issues/51).
