# Per Pulse v0.1.0a16

This alpha makes a past webpage observation inspectable and usable as attributed experience in another Work. It follows [v0.1.0a15](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a15).

## What's new

- **Inspect what was actually read.** A Work's **Web sources → View saved text** shows the native `read_web` text delivered at that time, not a new fetch from the current website. The UI preserves the original source URL, reading time, text range and SHA-256. Inspecting an old observation or reopening it after restart makes no new webpage or model request (#259).
- **Keep a selected passage for other Works.** From that saved text, select an exact excerpt, give it a title and optional note, and choose **Keep this passage**. This uses the existing Posture experience journal with the original Work and receipt as private provenance; the later Work receives the selected passage and note, not the originating Work's private transcript or URL. The action still works after the provider is disconnected (#260).
- **Give later decisions the right source semantics.** The normal pre-action expert/posture material now identifies such an example as a retained webpage observation, not a fresh webpage check, verified claim or accomplished result. The recipient can judge applicability and verify changing facts when needed (#261).

This release is a useful source-to-experience workflow, not a demonstrated increase in autonomous model quality. The synthetic World/Kernel and Chromium tests validate the mechanism and privacy boundaries; real provider decisions and cross-task transfer remain separate evaluations. Activity, weekly request accounting, pause/resume and Habitat retain the existing single-World behavior.

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a16-py3-none-any.whl` from this release once published.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a16-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a16-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example workspace runs without a provider. Before upgrading a real workspace, stop Per Pulse and back up the entire data directory; in-place downgrade is not guaranteed. See the [installation guide](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/install.md).
