# Per Pulse v0.1.0a21

This alpha makes it easier to collect several source files into one Home or Work draft and see each confirmed addition. It follows [v0.1.0a20](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a20).

## Attach a group of source files

- **Pick multiple files at once.** Open Materials, select text, PDF, PNG or JPEG files together, then attach them to the current unsent Home or Work draft. Each successful attachment keeps its source, and all attachments stay in the draft through a page refresh. The existing limit is five attachments per draft. If a batch reaches that limit or a file cannot be attached, successfully confirmed files remain available ([#281](https://github.com/Lightmaze/Per-Pulse/pull/281)).
- **See confirmed progress.** While further files are uploading, Materials shows how many have been attached (for example, **1 of 3 files attached**) instead of only a generic loading label. This reflects each actual saved attachment, not a prediction about pending uploads ([#282](https://github.com/Lightmaze/Per-Pulse/pull/282)).

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a21-py3-none-any.whl` from this release after publication.

Linux or macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a21-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a21-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example works without a model. For an existing workspace, stop Per Pulse and back up the full data directory before upgrading. See the [installation guide](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/install.md).
