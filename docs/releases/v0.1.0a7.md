# Per Pulse v0.1.0a7

This alpha update keeps ordinary work, saved experience and original sources
usable as the workspace grows. It includes the changes after
[v0.1.0a6](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a6).

## What changed

- **Continue model work reliably.** Plain JSON remains reply text across later
  turns and restart. Optional provider nulls, standard SSE line endings and a
  leading UTF-8 BOM are accepted; streamed refusal text remains readable.
  Complete file-action arguments containing literal omission markers can be
  approved using their original model-call authority.
- **Keep learning over long use.** Experience no longer stops at 128 lifetime
  records or 4 MiB of aggregate history. Current records, immutable prior
  revisions and feedback share the existing World SQLite database. Old sources,
  controls and revisions remain available. Experience lists and oversized
  details have bounded continuation paths.
- **Read and return to original material.** Long public webpages provide text
  ranges bound to the observed text and resolved source. Downloaded file results
  preserve their original bytes, including PDF output. Native file, Notice and
  lesson text can contain literal omission markers. Windows emoji paths use
  the correct UTF-16 byte lengths.
- **Keep the workspace state clear.** Opening a sourced page separates the
  original author's excerpt from your request in conversation, history and
  search. Failed browser draft saves retain editing and offer copying and retry.
  Configuration refresh reports configuration state. Diagnostic write failures
  use a bounded backlog and recovery without interrupting native work.

## Install or update

Requires Python 3.12 or later. Download
`per_pulse-0.1.0a7-py3-none-any.whl` from this release.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a7-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a7-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. Example mode uses separate sample data and makes
no model requests. Stop with Ctrl+C, then run without `--example` for your own
workspace. See the [installation guide](https://github.com/Lightmaze/Per-Pulse/blob/v0.1.0a7/docs/install.md) for configuration
and checking `SHA256SUMS`.

Before upgrading an existing installation, stop the service and back up the
complete data directory. The first start upgrades the World database to schema
v13 with a database backup. The first ordinary experience change imports its
legacy journal atomically and preserves the original components. Keep the
pre-upgrade backup for use with an older implementation.

## Verification

Release validation includes native persistence tests, Windows, Docker recovery,
Chromium journeys, source-archive verification and a wheel rebuilt from the
source archive without Node. The release workflow installs into empty Linux,
Windows and macOS environments and exercises the installed Linux application
in Chromium before publishing.

Provider regression journeys use explicit synthetic HTTP responses; their
native files, SQLite persistence, approvals, sources and browser actions are real.
The regional Habitat extension in
[draft #181](https://github.com/Lightmaze/Per-Pulse/pull/181) remains separate.
