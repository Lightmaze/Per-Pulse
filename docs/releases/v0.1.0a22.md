# Per Pulse v0.1.0a22

This alpha lets a continuing Work inspect public research metadata and selectable paper text without leaving its native source/history path. It follows [v0.1.0a21](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a21).

## Follow sources into a Work

- **Read public structured research sources.** The native `read_web` action accepts public HTTPS JSON/JSON-LD, XML/Atom/RSS, CSV and Markdown as text observations, alongside HTML and plain text. For example, a Work can inspect a bounded Crossref JSON API response. Existing URL, source digest, pagination and recorded-history behavior apply; the content is outside evidence, not commands ([#284](https://github.com/Lightmaze/Per-Pulse/pull/284)).
- **Read public paper PDFs.** For URLs served as `application/pdf`, `read_web` extracts selectable text with page markers, preserves a SHA-256 of the original PDF and marks pages without selectable text or extraction limits. A complete download is required; a partial PDF is reported as incomplete instead of presenting an unreliable text prefix. Limits: 8 MiB PDF response, 100 pages, 500,000 extracted characters. Image-only pages do not receive OCR ([#285](https://github.com/Lightmaze/Per-Pulse/pull/285)).
- **Return to what was actually observed.** The Work and its source observation remain linked in the existing World history; a later Work can revisit saved passages through the established provenance/experience route rather than relying on a changed live page. The model still needs a configured provider to choose sources and act on their contents.

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a22-py3-none-any.whl` from this release after publication.

Linux or macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a22-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a22-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example requires no model; reading live public sources in a Work requires a configured model. Stop Per Pulse and back up the full data directory before upgrading an existing workspace. See the [installation guide](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/install.md).

## Release verification

Merge only after exact-candidate native, Chromium, Windows and Docker checks and wheel/source-build plus Linux/macOS/Windows cold-install checks. The merged main commit then needs independent Verify before the release workflow may publish the matching version tag, wheel, source archive and `SHA256SUMS`. CI uses explicit model fixtures; it does not establish real-provider cross-Work learning gains.
