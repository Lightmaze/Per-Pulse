# Per Pulse v0.1.0a18

This alpha makes saved file and command observations usable in later Work, keeps more of a long task's earlier corrections in context, and makes older completed results findable from Home. It follows [v0.1.0a17](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a17).

## Continue from what actually happened

- **Start the next Work from a saved passage.** In the original Work's **Lessons and examples**, choose a saved file-reading or command-output excerpt and start a new task with it. The new Work receives an attributed historical observation, not a fresh file read or command execution. The source Work and its unsent draft remain private (#269).
- **Keep the right source label.** Where a test-double chose an excerpt from a real native command or file effect, the next Work keeps the `constructed_fixture` and `TEST_DOUBLE` marks. An operator-selected or genuine observed experience retains its own provenance; the interface does not silently upgrade test evidence (#269).
- **Continue a long conversation with its decisions.** When older tool output no longer fits the model context, the Harness can retain the surrounding correction and decision and replace the output body with a paged `read_history` reference. Original records stay in the same SQLite history (#270).
- **Find an earlier result again.** Home can browse completed Work results beyond the newest activity entries and return to the original source Work. Opening a result once does not make it disappear from this history (#271).
- **Grow the experience journal.** Automatic decision material loads at most 128 recent full candidates in SQL, and keeps ID/revision references for the rest. Explicit historical lookup still works. This bounds routine decoding; it is not a measured inference-speed or model-quality improvement (#272).

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a18-py3-none-any.whl` from this release when the package is published.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a18-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a18-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example workspace works without a model. For an existing workspace, stop Per Pulse and back up the entire data directory before upgrading; downgrade compatibility is not guaranteed. See [installation instructions](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/install.md).
