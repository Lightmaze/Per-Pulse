# Per Pulse v0.1.0a9

This alpha adds a way to connect Per Pulse to an OpenAI-compatible model server on another computer in your private network. It follows [v0.1.0a8](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a8).

## What's new

- **Use a model on a private LAN host.** Settings now offers a LAN connection template for POSIX terminals and Windows PowerShell, alongside the hosted and same-computer modes. A model must support streaming and tool calls.
- **Keep one continuing workspace.** LAN connections reuse the existing model adapter, World, Kernel, Work histories, budget accounting and approvals; no separate agent or session store is created.
- **Choose the network trust explicitly.** Private HTTP needs `P_PULSE_ALLOW_PRIVATE_HTTP=1`; credential-free mode also needs `P_PULSE_LOCAL_NO_AUTH=1`. The URL must contain a literal RFC1918 IPv4 or ULA IPv6 address, not a public address or hostname. The local interface remains bound to loopback.
- **Understand the exposure.** Plain HTTP does not encrypt model prompts, file context or replies on the private network. Use a trusted private LAN and model host; the UI provides this warning in English and Chinese.

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a9-py3-none-any.whl` from this release.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a9-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a9-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. Example mode uses separate sample data and does not send model requests. Stop the server and start without `--example` to use your own World. In Settings, open **How to connect a model**, select the LAN example, choose your shell and replace the sample IP and model ID with your own. Run `per-pulse doctor` before starting the service.

For upgrades, stop Per Pulse and back up the full data directory first. This version retains World schema v13 introduced in a7; existing histories, sources, feedback and local practice do not need a new session. See [installation](https://github.com/Lightmaze/Per-Pulse/blob/v0.1.0a9/docs/install.md) and [model connection](https://github.com/Lightmaze/Per-Pulse/blob/v0.1.0a9/docs/models.md).

## Verification and limits

The release process validates the exact committed candidate through native, Windows, Docker and Chromium journeys, builds wheel and source archives, checks reproducible contents and cold-installs on Linux, Windows and macOS before publication. Only a completed release run and public archive checksums establish the released artifact.

The LAN adapter's tests use explicit synthetic HTTP/SSE responses, and the installed Chromium setup test operates without a model. A physical LAN model connection and its reasoning or learning quality are not demonstrated by those tests. The regional Habitat action/return extension remains separate in [draft #181](https://github.com/Lightmaze/Per-Pulse/pull/181).
