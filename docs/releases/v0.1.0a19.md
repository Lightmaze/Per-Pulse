# Per Pulse v0.1.0a19

This alpha helps past corrections stay available as the experience journal grows and lets Work retain more of the real text it already observed on public webpages, including compressed pages and interrupted transfers. It follows [v0.1.0a18](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a18).

## Keep and reuse observations

- **Earlier compact corrections can reappear.** Before a later Work decision, the native experience journal considers its newest 128 complete entries plus up to 16 older compact entries (original records at most 4 KiB), subject to the same source, subject, revision, visibility and feedback checks. It retains the same World/SQLite and previous omissions ledger. This increases eligibility, not a guarantee of semantic relevance (#274).
- **Keep the text actually read.** When a public HTTPS text response disconnects or times out after sending usable text, Work retains the bounded observed prefix and labels it as incomplete. A partial read never asserts that the remote document was fully inspected (#275).
- **Read ordinary gzip webpages.** The native HTTPS reader accepts gzip-compressed text with independent 512 KiB bounds for network and decoded content. If a compressed transfer is interrupted after yielding usable text, its partial status is preserved. Source text travels through the existing Work observation, Home and restart path (#276).

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a19-py3-none-any.whl` from this release when published.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a19-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a19-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example workspace runs without a provider. For an existing workspace, stop Per Pulse and back up the entire data directory before upgrading; downgrade compatibility is not guaranteed. See [installation instructions](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/install.md).
