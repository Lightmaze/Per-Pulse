# Per Pulse v0.1.0a6

This alpha update makes old work easier to resume and improves model tool-call
continuation in everyday use. It contains the changes merged after
[v0.1.0a5](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a5).

## What changed

- **Find and resume earlier work.** Home's native `work.list` can page beyond
  its first 32 Works; `work.search(query, after_work_id?)` finds persistent
  Work titles and returns the original Work IDs. The browser sidebar displays
  recent Works first, lets you reveal more or search titles/descriptions, and
  keeps the currently open older Work available. See
  [#196](https://github.com/Lightmaze/Per-Pulse/pull/196),
  [#197](https://github.com/Lightmaze/Per-Pulse/pull/197) and
  [#198](https://github.com/Lightmaze/Per-Pulse/pull/198).
- **Resume autonomous use after long restarts.** Weekly request reservations
  can be recovered across multiple calendar weeks without losing their original
  World scope. See [#195](https://github.com/Lightmaze/Per-Pulse/pull/195).
- **Continue model tool work more reliably.** Provider compatibility now covers
  OpenAI/Azure tool-call arguments and streaming, Anthropic tool schema,
  DeepSeek reasoning content, Gemini tool signatures, and OpenRouter reasoning
  metadata carried across persisted turns. See
  [#199](https://github.com/Lightmaze/Per-Pulse/pull/199) and
  [model connections](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/models.md).

## Install or update

Requires Python 3.12 or later. Download
`per_pulse-0.1.0a6-py3-none-any.whl` from this release.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a6-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a6-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example uses separate sample data and
makes no model requests. Stop with Ctrl+C, then start `per-pulse` without
`--example` for your own Work.

For an existing installation, stop the service, back up the complete World data
directory, then install the new wheel in the same environment. See the
[installation guide](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/install.md)
for model configuration, source installation, and checking the SHA256SUMS asset.

## Verification scope

The integrated `main` commit
[`86a7b33`](https://github.com/Lightmaze/Per-Pulse/commit/86a7b33b73adb1395b3ed0cdf368770729fe575f)
passed all four independent
[Verify Per Pulse jobs](https://github.com/Lightmaze/Per-Pulse/actions/runs/42389671944):
native Verify, Windows, Docker recovery and Chromium browser journey.
The provider fix also has live-endpoint smoke evidence from its PR author for
Claude Haiku 4.5 and DeepSeek Flash doing file-tool calls with authored
instructions. These checks validate tool compatibility, not autonomous learning
quality or a blinded cross-Work transfer result.

This release does not change the earlier release assets. The regional Habitat
extension in [draft #181](https://github.com/Lightmaze/Per-Pulse/pull/181)
is not included.
