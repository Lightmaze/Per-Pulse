# Per Pulse v0.1.0a1

The first local alpha: one continuing Home conversation, focused pages, and
selected results returned with their original sources.

## Install

Requires Python 3.12 or later. Download the wheel below; the browser interface
is included. You do not need Node.js or a source build.

```sh
python -m venv .venv
```

Activate `.venv` (`source .venv/bin/activate` on Linux/macOS), then:

```sh
python -m pip install ./per_pulse-0.1.0a1-py3-none-any.whl
per-pulse --example
```

On Windows PowerShell, use the environment's executables directly:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a1-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. Ctrl+C stops the service. Run without `--example`
to begin your own workspace, and [connect a model](https://github.com/Lightmaze/Per-Pulse/blob/v0.1.0a1/docs/models.md)
for AI replies. The example runs without a model and is stored separately.

## Included

- English and Simplified Chinese interface, structured replies, live generation,
  visible steps, Stop and recovery controls.
- Home → focused page → selected result → original source, with drafts and
  reading positions preserved.
- Persistent conversations, earlier message search and original tool-result recall.
- Text and PDF materials, workspace file edits, downloads and conditional Undo.
- Background Pulse within an hourly budget, page connections and manual `/tick`.
- Examples and conditional lessons from corrections, with source links and controls
  for their use across pages.

Your work is stored in `~/.local/share/per-pulse` by default. Model file edits
apply by default; use `--ask-before-edits` to approve each one. Background Pulse
is on with a model connected; use `--no-pulse` to disable it.

The release workflow installs this exact wheel in fresh Linux, Windows and macOS
environments and checks startup, bundled resources, history and restart. Linux
also runs the installed first-use flow in Chromium. Full main CI is required on
the tagged commit before publication. Model replies in automated native tests
use explicit test transports; this alpha does not bundle a model.
