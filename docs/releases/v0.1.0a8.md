# Per Pulse v0.1.0a8

This alpha makes long-lived workspaces easier to browse and keeps source-bound experience and Home results usable after transient failures. These changes follow [v0.1.0a7](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a7).

## What's new

- **Find files beyond the first directory page.** The Materials picker can load more than the first 200 entries, continues within the existing bounded scan and access rules, and offers refresh when the directory changes. Bad continuation cursors produce a clear client error instead of an internal exception.
- **Keep the experience journal responsive.** Reading current experiences and their feedback or earlier versions uses batched SQLite queries while preserving their exact World and Work visibility. The number of records returned still affects response size; the optimization avoids per-record SQL round trips.
- **Preserve exact passages.** Lessons made from original assistant examples, reading receipts and command outputs can contain literal strings such as `[REDACTED]` without being mistaken for an incomplete source. Actual source completeness and byte limits are still checked.
- **Recover Home observation failures.** Home shows a refresh action and retains previously verified Work names as read-only context when an observation fails. It does not expose stale result actions or source links as if they had been revalidated.

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a8-py3-none-any.whl` from this release.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a8-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a8-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. Example mode uses separate sample data and makes no model requests. Stop with Ctrl+C and run without `--example` to use your own World. See the [installation guide](https://github.com/Lightmaze/Per-Pulse/blob/v0.1.0a8/docs/install.md) for model setup and checking `SHA256SUMS`.

Before updating an existing workspace, stop the service and back up the entire data directory. This release continues to use the World database schema v13 introduced with a7. Installations older than a7 migrate with a database backup; keep the prior backup for an older implementation.

## Verification and scope

The release pipeline checks the exact committed source with native tests, Windows, Docker recovery, Chromium browser journeys and distribution rebuilds, then cold-installs the wheel on Linux, Windows and macOS. The installed Chromium example and material journey run before publication. Review the exact commit's completed workflow jobs and the published archive checksums before treating an installed build as verified.

The model protocol tests use synthetic HTTP responses while exercising the real native World, Kernel, sources and UI. The regional Habitat extension remains in [draft #181](https://github.com/Lightmaze/Per-Pulse/pull/181), separate from this release.
