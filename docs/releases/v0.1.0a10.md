# Per Pulse v0.1.0a10

This alpha makes everyday Home/Work work easier to continue, from a pasted screenshot to older cited experience. It follows [v0.1.0a9](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a9).

## What's new

- **Paste a screenshot while writing.** In Home or Work, paste a PNG or JPEG into the composer. It is saved as a Materials-backed, source-linked attachment in that page's **unsent draft**. Continue editing text; the draft survives refresh and visiting other Works. The model receives it only after you choose **Send**.
- **Find an older cited experience again.** Native `posture.get(experience_id)` reopens one known entry directly from the long-lived World journal. Existing access and source privacy rules still apply.
- **Keep long chains going.** Native request attribution now follows the full causal ancestry of long Home/Work/tool chains rather than rejecting valid histories after 256 links; the existing weekly allowance and source checks still apply.
- **See your current work before technical details.** Activity keeps running/paused state, weekly autonomous requests, waiting Works, retained thoughts and recent sourced results in view. Hourly token accounting and connection editing are available in expandable details, with English/Chinese controls.

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a10-py3-none-any.whl` from this release.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a10-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a10-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. Example mode uses separate sample data and makes no model requests. Start without `--example` to use your own World. Configure the model through Settings and `per-pulse doctor`.

Stop Per Pulse and back up its complete data directory before upgrading. This version retains World schema v13 and your existing Home, Works, experiences and materials. See [installation](https://github.com/Lightmaze/Per-Pulse/blob/v0.1.0a10/docs/install.md) and [model connection](https://github.com/Lightmaze/Per-Pulse/blob/v0.1.0a10/docs/models.md).
