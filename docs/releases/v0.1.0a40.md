# Per Pulse v0.1.0a40

**Turn earlier work and background answers into new deliverables.** This alpha includes six merged changes [since v0.1.0a39](https://github.com/Lightmaze/Per-Pulse/compare/v0.1.0a39...a50306c03cd48be0d649b266d610c5cf83839fe3).

## Keep the original work reachable

Find a completed file by its path after long Work histories, retain the verified source read and its order even when older runtime events are evicted, and return the original file to Home without repeating the write. Reopen or undo the original result using its native receipt.

## Use saved Pulse answers

Reopen a read background answer from Home even when there are only a few results. A propagated answer opens the completed response rather than its incoming material. Adopt it into Home, select a passage and create a new independent Work from that passage. The later Work can produce a file, deliver it Home and keep the original answer reachable after restart.

## Install or update

Python 3.12 or later is required. Stop Per Pulse and back up the complete World/workspace directory. Download `per_pulse-0.1.0a40-py3-none-any.whl` and `SHA256SUMS` from this release and follow [installation and checksum verification](../install.md).

Linux/macOS, using your existing virtual environment:

```sh
python -m pip install --upgrade ./per_pulse-0.1.0a40-py3-none-any.whl
per-pulse
```

Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade .\per_pulse-0.1.0a40-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe
```

Open **http://127.0.0.1:8000**. Use `per-pulse --example` to explore offline.

## Release acceptance

The source baseline [a50306c0](https://github.com/Lightmaze/Per-Pulse/commit/a50306c03cd48be0d649b266d610c5cf83839fe3) passed independent [main Verify #45920120242](https://github.com/Lightmaze/Per-Pulse/actions/runs/45920120242). Publish only after exact candidate and merged-main CI, distribution checksums, wheel-from-sdist equivalence and fresh wheel installs on Linux, Windows and macOS. The Linux package job continues a real offline World created by the digest-pinned published a39 wheel and runs the saved Pulse answer-to-new-Work-to-file journey in Chromium against the isolated candidate wheel. Model responses in the latter journey are explicit synthetic HTTP; the World, Kernel, SQLite and files are real.
