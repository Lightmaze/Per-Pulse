# Per Pulse v0.1.0a17

This alpha carries a previously saved webpage passage into a later Work's actual first request, including after a restart, and makes file browsing steadier while a Work is modifying its folder. It follows [v0.1.0a16](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a16).

## What's new

- **Continue from the observation you chose.** After keeping a passage in Work A, choose **Continue in a new Work**. The user writes Work B's task, and the server places the exact saved passage, title, note and experience ID in that first request as past source data. The originating Work remains private; the original source linkage and Home return stay available (#263, #265).
- **Resume after a restart.** On reopening Work A, **Lessons and examples** can start another Work from the same saved webpage observation. The app does not re-save the example or visit the website again (#267).
- **Trust the saved version.** While a passage is saving, its title, text and note cannot be edited into a falsely saved state. Completion from a previous editor view cannot update a newly opened passage (#264).
- **Continue through changing folders.** Materials and the native file browser can keep paging after files are added or removed. When the old position is gone, they say so and restart; the continuation cursor does not reveal protected filenames or accept fabricated protected anchors (#266).

All changes reuse the native World, Kernel and Posture history. The source-to-Work path provides an opportunity for experience to shape a later decision; actual model learning and comparative result quality still require authorized real-provider evaluation. No live-provider success or reduction in model cost is claimed.

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a17-py3-none-any.whl` from this release once published.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a17-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a17-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example workspace requires no provider. Before upgrading a real workspace, stop the service and back up its entire data directory; downgrading is not guaranteed. See the [installation guide](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/install.md).
