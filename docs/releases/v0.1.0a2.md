# Per Pulse v0.1.0a2

An alpha update for doing actual work and continuing autonomously in the same Home, Work and World. This release follows [v0.1.0a1](v0.1.0a1.md); it does not replace the first release's tag or files.

## Install

Requires Python 3.12 or later. Download `per_pulse-0.1.0a2-py3-none-any.whl` from this release. The compiled browser interface is included; Node.js is not required to install.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a2-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a2-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example needs no model and uses separate sample data. Stop with Ctrl+C; run `per-pulse` without `--example` for your own workspace. [Connect a model](../models.md) before expecting AI replies or autonomous work.

## What's new since a1

- **First autonomous departure.** With a compatible model connected, set a weekly request allowance in Activity and choose **Start autonomous practice**. A new World can create its first SELF activity without a fabricated user message. The normal Home/Work tools produce persistent, source-linked results.
- **One bounded continuation.** Weekly autonomous request counts are stored in the original World. Each physical send (including retries, delegated work and semantic review) consumes a slot. Direct user messages remain available separately. A pause or depleted allowance stops new sends; confirmed file effects stay saved, and the unfinished Work can continue from its prior context after an allowance increase or restart. Uncertain effects require review rather than blind replay.
- **Practical work.** Full document rewrites now have a 1 MiB durable action/message envelope, with compact previews, exact file download, approval and conditional Undo. The workspace also has improved materials handling and long history/tool-result recall.
- **Local usability.** Continued English/Chinese Home/Work controls and provider setup instructions, including Azure-compatible configuration.

## Important boundaries

This is a local single-user alpha. No AI model or API credits are bundled. Automated verification uses explicitly synthetic model decisions against the production World, Kernel, browser and storage, not evidence of real-model self-improvement. Weekly limits count requests, **not billable dollars or tokens**; monitor your provider costs independently. Pausing cannot retract a request already sent, and unknown physical effects are not replayed automatically.

`--no-pulse` disables the underlying background profile. File edits follow existing workspace approval/auto-apply and Undo controls. Read [Autonomous practice](../autonomous-practice.md), [Installation](../install.md), [Known limitations](../known-limitations.md) and [Security](../../SECURITY.md) before using private data. Keep a backup when upgrading a workspace; in-place downgrades are not guaranteed.

The release pipeline verifies the bundled wheel and source archive, rebuilds from the source archive without Node, installs the wheel in clean Linux/Windows/macOS environments, and checks native first use/restart and Linux Chromium. The published `SHA256SUMS` authenticates the release archives.
