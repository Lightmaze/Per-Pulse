# Per Pulse v0.1.0a20

This alpha makes two everyday Home/Work handoffs more direct: keeping an exact passage from a webpage already read, and keeping text when a paste also contains a file the app cannot attach. It follows [v0.1.0a19](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a19).

## Keep source material and draft text

- **Use the passage you selected.** Open a Work's saved Web sources, inspect the originally observed HTTPS text, select the passage in that text and choose **Use selected passage**. The exact selection fills the existing experience editor; you can still edit the title or note before saving. Selection must be entirely within that observation and at most 8 KiB. The saved example retains its original Work and observation source for later reuse and navigation ([#278](https://github.com/Lightmaze/Per-Pulse/pull/278)).
- **Keep your text when a clipboard contains an unsupported file.** If you paste text together with a file the app cannot accept, the browser's normal text paste continues and the composer explains that the file was not attached. Subsequent editing clears that notice. Supported PNG/JPEG, text and PDF attachments continue to use the existing durable draft flow ([#279](https://github.com/Lightmaze/Per-Pulse/pull/279)).

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a20-py3-none-any.whl` from this release after publication.

Linux or macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a20-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\\.venv\\Scripts\\python.exe -m pip install .\\per_pulse-0.1.0a20-py3-none-any.whl
.\\.venv\\Scripts\\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example works without a model. To upgrade an existing workspace, stop Per Pulse and back up its entire data directory first. Downgrading is not guaranteed. See the [installation guide](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/install.md).
