# Per Pulse v0.1.0a5

This alpha maintenance release corrects the **source archive**, without changing
the installed application behavior delivered in [v0.1.0a4](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a4).

## What changed since a4

- Source distributions now contain the two exact, public **synthetic TLS test
  fixtures** (`tests/fixtures/web_tls/cert.pem` and `key.pem`). An extracted
  source archive can run the HTTPS/TLS network tests without borrowing files
  from a Git checkout.
- Distribution verification now **requires** both fixtures and checks their fixed
  SHA-256 hashes. Other certificates, private keys, duplicate members,
  unexpected paths and certificates in the installed wheel remain prohibited.
- Home, Work, Pulse, model provider interfaces, Materials, web reading and
  the World database remain unchanged from a4.

This release addresses [source archive issue #192](https://github.com/Lightmaze/Per-Pulse/issues/192).
The published a4 assets and tag have not been altered.

## Install

Requires Python 3.12 or later. Download
`per_pulse-0.1.0a5-py3-none-any.whl` from this release.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a5-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a5-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example uses separate sample data and
needs no model. Stop with Ctrl+C, then use `per-pulse` without `--example`
for your own workspace.

[Installation](https://github.com/Lightmaze/Per-Pulse/blob/v0.1.0a5/docs/install.md)
and [Connect a model](https://github.com/Lightmaze/Per-Pulse/blob/v0.1.0a5/docs/models.md)
have provider and upgrade instructions. Always stop the running service and
back up your data directory before upgrading. This maintenance release does
not alter the World schema.

Automated checks use explicit model and network fixtures; they do not
establish real-model learning or general Internet connectivity.
