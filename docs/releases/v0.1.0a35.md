# Per Pulse v0.1.0a35

**Carry real work from one Work to the next, even when browser or network acknowledgements fail.** This release packages the 11 merged changes [#340](https://github.com/Lightmaze/Per-Pulse/pull/340) through [#350](https://github.com/Lightmaze/Per-Pulse/pull/350) after [v0.1.0a34](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a34).

## Keep the task and its earlier corrections

An ordinary later Work now offers up to two older task-cued lessons from its existing World/Posture journal alongside recent experiences, even after a long SQLite history and restart. Both English and unspaced Chinese task phrases are handled. An offered lesson is attributed candidate context; the normal Work decision still chooses whether it applies and must obey the source revision, ownership and withdrawal status. No second memory database or model call is introduced.

When conversation history is compacted, the original Work's actual task is preserved for the later decision. If a selected source experience changes while expert computation is in flight, the original World is checked again before the candidate is used.

## Complete the handoff despite lost receipts

Creating a new Work, sending an ordinary sourced message, transferring selected results between Works, and returning a file-backed result Home now resume from the same accepted native request when a network response is lost or the browser is refreshed. A completed historical Home Return is reconstructed from its original material receipt; a new file action still verifies the current bytes. An uncertain physical effect is never executed again merely because the receipt disappeared.

The /tick interface no longer reports completion against an earlier snapshot that is missing the last reply. Source-linked messages, Home and Work drafts, and return anchors survive browser restart.

## Install or update

Python 3.12 or later. Stop the local service and back up the complete workspace data directory before installing the new wheel. Download `per_pulse-0.1.0a35-py3-none-any.whl` from this release after publication.

Linux/macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a35-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a35-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The offline example needs no model. Live work needs a separately configured provider.
