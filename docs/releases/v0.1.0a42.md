# Per Pulse v0.1.0a42

**Learn from delivered work, even when the original conversation has grown long.** This alpha includes four merged changes [since v0.1.0a41](https://github.com/Lightmaze/Per-Pulse/compare/v0.1.0a41...c9730cc76baeb685fc60bca77acf431bc4814278).

## Give feedback where you see the result

Open experience feedback directly from a delivered Home file or a completed Work answer. The original result is selected for you, including older results outside the recent history window. If the source temporarily cannot be loaded, retry without losing the feedback draft.

## Continue a long Work

When the model context is fitted to its available window, the earlier history remains in the World. Pre-action experience computation and delivery review continue to run. The browser journey checks a later file decision, the resulting source selection, the delivered file's exact bytes and restart.

## Install or update

Python 3.12 or later is required. Stop Per Pulse and back up the complete World/workspace directory. Download `per_pulse-0.1.0a42-py3-none-any.whl` and `SHA256SUMS` from this release and follow [installation and checksum verification](../install.md).

Linux/macOS, using your existing virtual environment:

```sh
python -m pip install --upgrade ./per_pulse-0.1.0a42-py3-none-any.whl
per-pulse
```

Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade .\per_pulse-0.1.0a42-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe
```

Open **http://127.0.0.1:8000**. Use `per-pulse --example` to explore offline.

## Release acceptance

The source baseline [c9730cc7](https://github.com/Lightmaze/Per-Pulse/commit/c9730cc76baeb685fc60bca77acf431bc4814278) passed independent [main Verify #46147273474](https://github.com/Lightmaze/Per-Pulse/actions/runs/46147273474). Publish only after exact candidate and merged-main CI, distribution checksums, wheel-from-sdist equivalence and fresh wheel installs on Linux, Windows and macOS. The Linux package job must continue a World created by the digest-pinned published a41 wheel and execute the historical feedback, compacted Work file decision and background-result journeys in Chromium against the isolated candidate wheel. The browser journeys use explicit synthetic HTTP model responses with real World, Kernel, SQLite and files.
