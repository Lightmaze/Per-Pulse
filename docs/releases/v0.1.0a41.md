# Per Pulse v0.1.0a41

**Let earlier Pulse work inform a new task, and let later results refine the experience.** This alpha includes nine merged changes [since v0.1.0a40](https://github.com/Lightmaze/Per-Pulse/compare/v0.1.0a40...02be3f48effe330cebf9dd806e7a8ab6fcd99826).

## Bring relevant earlier work into a new decision

Start an ordinary Work without having to locate an earlier Pulse answer yourself. Completed, task-matching answers can be offered before the next decision, with their original source and a relevant passage. Competing conditions can surface different answers; newer unfinished work does not displace a relevant completed result. Matching supports English and Chinese.

## Learn from the work that follows

Open the original Work to save, revise or withdraw an experience. Link feedback to the later result that motivated it. If the experience changes while you are writing feedback, your draft and selected result remain available for review. Use a result-only report to record a historical outcome without pausing the current guidance. An explicit withdrawal still stops future reuse while preserving the original answer and past work.

## Install or update

Python 3.12 or later is required. Stop Per Pulse and back up the complete World/workspace directory. Download `per_pulse-0.1.0a41-py3-none-any.whl` and `SHA256SUMS` from this release and follow [installation and checksum verification](../install.md).

Linux/macOS, using your existing virtual environment:

```sh
python -m pip install --upgrade ./per_pulse-0.1.0a41-py3-none-any.whl
per-pulse
```

Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade .\per_pulse-0.1.0a41-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe
```

Open **http://127.0.0.1:8000**. Use `per-pulse --example` to explore offline.
