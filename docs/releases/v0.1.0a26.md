# Per Pulse v0.1.0a26

Continue a real task from a correction saved in an earlier Work, and keep the later Work's next decision anchored to the correction's currently shared revision. This alpha includes three already-merged changes after [v0.1.0a25](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a25).

## Carry a sourced correction into another Work

- **Continue from a correction** ([#298](https://github.com/Lightmaze/Per-Pulse/pull/298)). In a Work's saved experiences, choose **Start a Work from this saved experience** to create a new Work from an eligible correction. The verified lesson and original source Work remain linked; private dialogue is not copied into the new Work.
- **See when guidance changes** ([#299](https://github.com/Lightmaze/Per-Pulse/pull/299)). The destination Work records the selected experience revision and shows when the source becomes revised, withdrawn, local-only or unavailable. You can return to the source. Prior messages and completed files remain historical artifacts.
- **Refresh before later decisions** ([#300](https://github.com/Lightmaze/Per-Pulse/pull/300)). Ordinary subsequent Kernel model rounds, including continuation after approval, recheck the native World/Posture record. An active revised lesson is supplied as attributed current source data; a withdrawn or unavailable experience is not presented as current shared guidance. No new model loop, second store or implicit action approval is created.

For a practical walkthrough, see [Install / Continue from a saved correction](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/install.md#continue-from-a-saved-correction).

## Install or update

Requires Python 3.12 or later. After this release has been published, download `per_pulse-0.1.0a26-py3-none-any.whl` from its assets.

Linux or macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a26-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\\.venv\\Scripts\\python.exe -m pip install .\\per_pulse-0.1.0a26-py3-none-any.whl
.\\.venv\\Scripts\\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example is offline and does not require a model. Stop Per Pulse and back up the entire data directory before upgrading an existing workspace. Consult the [installation guide](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/install.md).
