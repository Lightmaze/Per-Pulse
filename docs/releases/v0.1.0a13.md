# Per Pulse v0.1.0a13

This alpha helps a later Work find and safely continue earlier Habitat work without requiring the user to remember the region's name. It follows [v0.1.0a12](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a12).

## What's new

- **Discover past regions before the next decision.** The normal first Home/Work model context includes a small live directory of up to eight existing Habitat region names (without files or private text). A later Work can list all existing region names, then search across their saved text with `habitat_observe(find)`, with exact excerpts, character offsets, file SHA-256 and verified writer provenance when available. Incomplete coverage and continuation are reported rather than silently represented as exhaustive (#245, #246, #247).
- **Continue without overwriting another Work.** A Habitat write or append can carry the SHA-256 observed at read time. The existing managed file lock checks the current version during execution, including after **Allow once** has been pending; a changed file prompts a fresh read instead of an outdated write (#244).
- **Get back to your work even while pausing.** Activity can close while a weekly allowance change is still processing. The original native pause continues, and returning to the source Work is no longer blocked by the Activity dialog (#248).

Home, Works and Habitat still share one World/Kernel/SQLite owner. **Habitat writes require Allow once and do not offer Undo.** Regional names in a model request are a discovery hint; the model must still decide to search and read. Existing CI uses synthetic HTTP model choices to test native effects and browser behavior, not a live-model learning result.

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a13-py3-none-any.whl` from this release.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a13-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a13-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. Example mode does not call a model. Stop the existing service and back up the entire data directory before upgrading. This release retains World schema v13; consult [the installation guide](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/install.md) for configuration, checksums and platform details.
