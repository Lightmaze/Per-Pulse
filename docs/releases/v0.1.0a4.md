# Per Pulse v0.1.0a4

This alpha adds image materials and public webpage reading, and improves
continuation through long conversations and background activity.

## What changed since a3

- **Images in Materials.** Upload and preview still PNG or JPEG images up to
  1 MiB and 8,388,608 pixels, attach an exact source version, and send the original
  image bytes to your configured image-compatible model. Original downloads
  and source references remain available after a restart.
- **Public webpage reading.** Ask the model to read a public HTTPS HTML or
  plain-text page. The resulting observation keeps its source URL, reading
  time, extracted passage and partial-reading status in the original Work.
  Saved observations can be recalled from history after a restart without
  fetching the page again. Stop and a total deadline bound each new read.
- **PDF coverage.** PDF reading and search describe their coverage as extracted
  text, including pages that mix text and images. Open the original PDF for
  its visual details.
- **Continue long conversations.** An oversized historical opening no longer
  stays pinned in every later context projection. The current exchange stays
  intact and may still exceed the estimate.
- **Room for your next message.** With more than one worker, background work
  leaves capacity for user-directed turns within the existing worker limit.
  Running work is not interrupted, and messages in the same context continue
  in order.
- **Stable source lookup.** Looking up a consultation's original source uses
  a database index as completed consultations accumulate.

## Install

Requires Python 3.12 or later. Download
`per_pulse-0.1.0a4-py3-none-any.whl` from this release. The browser interface is
bundled; Node.js is not required to install it.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a4-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a4-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example uses separate sample data and needs
no model. Stop with Ctrl+C, then run `per-pulse` without `--example` for your
own workspace (on Windows, use `.\.venv\Scripts\per-pulse.exe`).
[Connect a model](https://github.com/Lightmaze/Per-Pulse/blob/v0.1.0a4/docs/models.md) for AI replies; image reading requires a model
that accepts image input.

## Keep your work when upgrading

Stop the service and copy the complete data directory to a backup before
installing the new wheel in the same environment. Your existing workspace
remains outside the installation.
The World schema v12 migration adds a source lookup index, preserves
stored business records, and uses the existing pre-migration database backup.
Restore an older workspace image with its matching implementation first, then
upgrade that restored data directory. See [Installation](https://github.com/Lightmaze/Per-Pulse/blob/v0.1.0a4/docs/install.md) and
[Workspace images](https://github.com/Lightmaze/Per-Pulse/blob/v0.1.0a4/docs/image.md).

Web reading covers public HTTPS text pages; it does not sign in to websites.
PDF tools continue to read extracted text. Automated verification uses explicit
model and website fixtures with the native runtime, persistence and browser;
these checks establish behavior rather than model learning outcomes.
