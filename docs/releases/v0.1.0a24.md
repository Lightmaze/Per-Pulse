# Per Pulse v0.1.0a24

Bring mixed text and images into one persistent task, and pause autonomous practice without losing a newer weekly allowance. This alpha follows [v0.1.0a23](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a23) and packages the previously merged changes in [#291](https://github.com/Lightmaze/Per-Pulse/pull/291) and [#292](https://github.com/Lightmaze/Per-Pulse/pull/292).

## Work with complete input

- **Paste text and images together.** When the clipboard contains ordinary task text plus a supported PNG/JPEG, Home and Work preserve the text and attach the image in the same unsent draft. Refreshing keeps the draft and its original uploaded material. The model receives them only after Send. Image-only paste and ordinary text paste continue as before ([#291](https://github.com/Lightmaze/Per-Pulse/pull/291)).
- **Pause without reverting another view's settings.** Pausing autonomous practice disables autonomous requests while the existing World transaction retains the latest persisted weekly request limit, even if an older Activity tab holds a stale value. Resuming or saving a new limit still requires an explicit valid allowance. This remains one World/Kernel with durable SELF history and accounting ([#292](https://github.com/Lightmaze/Per-Pulse/pull/292)).

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a24-py3-none-any.whl` from this release after publication.

Linux or macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a24-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a24-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example workspace runs without a model. Stop Per Pulse and back up your complete data directory before upgrading an existing workspace. See the [installation guide](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/install.md).
