## Keep the current Work moving

Long Work histories require less repeated native validation and projection. Earlier unsettled turns remain visible to admission. The expert view retains the latest user purpose before actions and delivery, and a resumed background Work preserves its original purpose. Delivery review can revise a prepared report before it reaches Home.

The native runtime regression now exercises 200 foreground follow-ups and two consecutive autonomous Pulse activations separated by a cold restart, with source-version reads, distinct file outputs, Home delivery, pause, durable budget and independent Undo. The model transport in this regression is explicit synthetic HTTP.

## Read, attach and continue writing

Return to the original reading position when navigating back from a source. Keep Work creation drafts during startup and keep pending intent in the World where it started. Insert a page reference or attach source files and continue typing in the original composer; a late cancelled attachment response does not alter another Work's draft.

## Install or update

Python 3.12 or later is required. Stop Per Pulse and back up the complete World/workspace directory. Download `per_pulse-0.1.0a39-py3-none-any.whl` and `SHA256SUMS` from this release and follow [installation and checksum verification](../install.md).

Linux/macOS, using your existing virtual environment for an update:

```sh
python -m pip install --upgrade ./per_pulse-0.1.0a39-py3-none-any.whl
per-pulse
```

Windows PowerShell, using your existing virtual environment:

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade .\per_pulse-0.1.0a39-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe
```

Open **http://127.0.0.1:8000**. For a new installation, use `per-pulse --example` to explore offline.
