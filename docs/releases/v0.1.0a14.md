# Per Pulse v0.1.0a14

This alpha makes ordinary multi-source work easier and keeps material sources available as a World grows. It follows [v0.1.0a13](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a13).

## What's new

- **Bring in several sources at once.** Drop or paste PNG/JPEG screenshots, text files and PDFs together into a Home or Work composer. Up to five attachments are saved with their original source references in the unsent draft, including across refresh and navigation. A model is contacted only when you press **Send**. When a batch stops at a limit or file error, successfully added sources remain and the composer shows the reason (#250).
- **Keep collecting materials over a long-lived World.** Immutable material receipts now live in indexed rows of the existing World SQLite rather than an ever-growing page JSON object. There is no longer a lifetime ceiling of 1,024 receipts. Existing receipt IDs, file bytes, SHA-256 and attribution are retained; older embedded receipts are moved in one database transaction on first opening the World (#251).

The model needs to support image input to inspect PNG/JPEG materials. PDF reading covers extracted text. These changes retain the same Home/Work and Kernel, rather than adding another file store or session owner.

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a14-py3-none-any.whl` from this release.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a14-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a14-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. Example mode works without a model. Before upgrading an existing World, stop the service and back up its complete data directory. The material-index upgrade retains the existing World database and moves legacy receipt records transactionally on first open; old application versions are not guaranteed to read upgraded data. See [installation](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/install.md) for platform setup and data safety.
