# Per Pulse v0.1.0a30

Start a new Work directly from a file already made in Home or another Work. This release packages the merged [#313](https://github.com/Lightmaze/Per-Pulse/pull/313) on top of [v0.1.0a29](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a29).

## Continue verified source into a new Work

1. Complete a native file-producing action in Home or a Work. Open its confirmed file result and choose **Start a new Work with this file**.
2. Name the new Work and describe the result you want. Per Pulse verifies the original Kernel action and current file SHA-256, then attaches the existing World-owned source material to the first task **before** its first model stimulus is queued.
3. Continue work on that file, approve or undo file edits according to your existing settings, and return a selected result Home. After restarting the same SQLite World, inspect the original source, its receipt and the new artifact.

You can still attach a file to an **existing** Work's unsent draft instead. These paths use the original World/Kernel/SQLite and authorization boundary; they do not duplicate the file's authority or silently execute a new file effect. If the file changed from its original action, reopen the source result.

The native Python and Chromium regression in #313 exercises file lookup, approved new output, exact bytes/SHA-256 and restart. The browser fixture supplies **synthetic model tool choices**, not evidence that a live model will naturally choose to retrieve past experience. [#51](https://github.com/Lightmaze/Per-Pulse/issues/51) retains its separate provider, budget and independent-review requirements.

## Install or update

Python 3.12 or later. Download `per_pulse-0.1.0a30-py3-none-any.whl` from this release when published.

Linux/macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a30-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a30-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example needs no provider; real model execution requires configuration. Stop Per Pulse and back up the entire data directory before updating an existing World.

## Release gate

Require PR and push Verify against this exact candidate head, then reproducible wheel/sdist and isolated Ubuntu/Windows/macOS cold installs. The Ubuntu installed wheel must pass the file-to-new-Work Chromium journey (including approved native file output and restart), in addition to existing installed flows. Only merge after review; require a separate main Verify on the merge SHA before publishing the new immutable tag, wheel, sdist and SHA256SUMS. Do not overwrite any previous release.
