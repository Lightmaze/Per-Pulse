# Per Pulse v0.1.0a11

This alpha keeps the contents of a long conversation available when a single user message or tool result is larger than the model's current context. It also improves everyday model/tool and image handling. It follows [v0.1.0a10](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a10).

## What's new

- **Continue a long tool result without repeating the action.** If a file read or other saved tool result exceeds the context budget, the model receives a bounded preview with its original source address. It can read the rest by original message ID and character offset during the same Work turn. Even after later history eviction, the reference points to the saved source rather than an unresolvable copy (#238).
- **Continue a long pasted task.** An oversized, already-saved user message enters the model request with a visibly incomplete preview and an exact `read_history(role="user")` address. Its full text can be read in pages in the same turn; the user does not need to resend it (#239).
- **Let the model correct a tool-call mistake.** Unknown tool names and arguments that are not one JSON object reach the model as a helpful tool error, with the available tools, so it can try the right call without losing the turn (#234).
- **Use ordinary screenshots and phone photos.** PNG and JPEG material input now accepts originals up to 32 MiB and 50 megapixels. Models receive the original when within their input envelope, otherwise an explicitly scaled image copy; the original remains available to download (#233).
- **Continue when a text-only model rejects an image.** A rejected image request can be retried without the image with a clear limitation note. The original remains in Materials; the model is not told it saw the image (#237).
- **Explain autonomous weekly limits at the point of interruption.** A background turn held by its weekly request allowance or an unconfirmed startup has an actionable status, rather than only a machine error code.

These changes use the existing World, Kernel, SQLite histories and Home/Work sources. Background activity still obeys the user's weekly request allowance and pause controls.

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a11-py3-none-any.whl` from this release.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a11-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a11-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. Example mode contains its own sample World and never calls a model. Stop the service, back up the entire data directory, then install the new wheel in your existing environment for an upgrade. This release retains the existing World schema v13. Read the [installation guide](https://github.com/Lightmaze/Per-Pulse/blob/v0.1.0a11/docs/install.md) for model settings, backup instructions and checksum verification.

## Verification and remaining work

Publication requires the exact candidate's native, Windows, Docker and Chromium checks; reproducible wheel/source validation; and clean Linux/Windows/macOS installation. The source/continuation tests use synthetic HTTP model decisions with real Kernel and persisted histories. They verify that the route works, not that any specific live model chooses to read all pages autonomously.

The regional Home→Work→Work→Home Habitat journey remains in [Draft #181](https://github.com/Lightmaze/Per-Pulse/pull/181) and is not included in this release.
