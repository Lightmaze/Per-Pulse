# Per Pulse v0.1.0a15

This alpha keeps external observations and earlier results useful as Home and Works grow. It follows [v0.1.0a14](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a14).

## What's new

- **Keep a passage you actually read.** After a native `read_web` call succeeds, the model can retain an exact excerpt as an example, with the original HTTPS URL, observation time, text-version digest and source Work. The existing experience path makes that example available to later Works. A receiving Work sees the selected passage, not the originating Work's private conversation (#256).
- **Find files beyond the first workspace page.** Native `browse_workspace` can return a continuation cursor for subsequent files and directories. If the directory changes between scans, it reports that change and lets the Work start a fresh scan (#255).
- **Reopen earlier file results.** A Work with a long history now offers **Show earlier file results**, fetching prior verified action results in bounded pages. Preview, download, carry to another context or conditionally Undo using the original action and file version (#257).
- **Follow sources in Chinese.** Chinese UI copy now covers source Work and material recovery, including the handoff path (#254).

These features reuse the same World, Kernel and Posture journal. Saved observations provide provenance and later context; natural model adoption and outcome improvement still depend on the configured model and are not certified by synthetic integration tests.

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a15-py3-none-any.whl` from this release once published.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a15-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a15-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. Example mode works without a model. Before upgrading a real workspace, stop the service and back up the entire data directory. No in-place downgrade is guaranteed. See the [installation guide](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/install.md).
