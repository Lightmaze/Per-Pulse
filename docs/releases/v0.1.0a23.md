# Per Pulse v0.1.0a23

Find precise passages in external research, preserve the version actually observed, and reuse them across Works. This alpha follows [v0.1.0a22](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a22) and packages changes already merged in [#287](https://github.com/Lightmaze/Per-Pulse/pull/287), [#288](https://github.com/Lightmaze/Per-Pulse/pull/288) and [#289](https://github.com/Lightmaze/Per-Pulse/pull/289).

## Continue work with sourced evidence

- **Find evidence in long public material.** The native `read_web` action can find a phrase beyond the first text passage in public HTML, JSON/XML/CSV responses, or selectable PDF text, then use `next` for later matches. It returns a bounded exact excerpt, source/version checks and PDF page attribution where available. A changed source digest stops continuation rather than mixing observations. Search covers observed/extractable text, not scanned images ([#287](https://github.com/Lightmaze/Per-Pulse/pull/287)).
- **Search a saved observation in its original Work.** Open the earlier webpage/PDF/data observation, locate matching text without re-fetching its live URL, and place a continuous passage directly into the existing experience editor. Save via the original sourced lesson path; later Works can reuse it and Home can return to its source. Saved text is historical evidence, not verification that the live source has remained unchanged ([#288](https://github.com/Lightmaze/Per-Pulse/pull/288)).
- **Pause without changing a draft allowance.** Pausing autonomous practice uses the limit already saved in the World, even if the weekly request limit input was edited but not saved or left blank. Starting practice and saving an edited limit retain their existing validation. The ongoing SELF identity and previous request accounting remain durable ([#289](https://github.com/Lightmaze/Per-Pulse/pull/289)).

## Install or update

Requires Python 3.12 or later. Download `per_pulse-0.1.0a23-py3-none-any.whl` from this release after publication.

Linux or macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a23-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a23-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. Example mode needs no model. Live source reading, natural later-Work decision-making and autonomous model requests require a configured provider. Stop Per Pulse and back up the complete data directory before upgrading an existing workspace. See the [installation guide](https://github.com/Lightmaze/Per-Pulse/blob/main/docs/install.md).
