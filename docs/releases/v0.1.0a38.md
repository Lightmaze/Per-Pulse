# Per Pulse v0.1.0a38

**Find a file from an earlier Work, use its exact version in a new Work, and bring both the source and the new result back to Home.** This alpha packages [#362](https://github.com/Lightmaze/Per-Pulse/pull/362), [#363](https://github.com/Lightmaze/Per-Pulse/pull/363) and [#364](https://github.com/Lightmaze/Per-Pulse/pull/364) since [v0.1.0a37](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a37).

## Continue from a real earlier file

Ask a new Work to find an earlier Work by title and use one of its completed files. The native Work tools can page through original file receipts, including path, SHA-256 and action identity, even when the earlier conversation has left model context. The model can read the matching file version and produce a separate result using the normal file-action controls.

Home can show the verified input file alongside the new output when the later Work reports both. Each link opens or downloads the corresponding file, with its own original Work and action. The input attribution requires a successful version-matched read before the output action. Offline restart preserves both links and source navigation. Undoing the input invalidates its old preview and download but does not delete the independent output.

Historical file browsing uses an index in the existing Kernel SQLite database. Existing Worlds acquire the index when opened; no separate file or memory store is needed.

## Install or update

Python 3.12 or later is required. Stop Per Pulse and back up the complete World/workspace directory before updating. Once published, download `per_pulse-0.1.0a38-py3-none-any.whl` and `SHA256SUMS` from this release. See [installation and checksum verification](../install.md).

Linux/macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a38-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a38-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example runs offline; live Work requires a configured provider.

Publish only after the new candidate's Push and PR checks, independent main CI on the exact release commit, distribution and wheel-from-sdist content verification, SHA256SUMS, and clean Linux/Windows/macOS wheel installation. The installed Chromium journey must discover the original Work, inspect file receipts, read the matching version, create the derived file, open both original-byte downloads from Home, restart offline and verify independent Undo.

The browser model responses are explicit synthetic HTTP; the World, Kernel, SQLite, file actions and browser are the actual product. Real-model transfer evaluation remains under [issue #51](https://github.com/Lightmaze/Per-Pulse/issues/51). The published v0.1.0a37 tag and assets remain unchanged.
