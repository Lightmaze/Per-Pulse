# Per Pulse v0.1.0a36

**Get a real Work file back in Home, inspect it, and download the original.** This preview release includes the four merged changes [#352](https://github.com/Lightmaze/Per-Pulse/pull/352) through [#355](https://github.com/Lightmaze/Per-Pulse/pull/355) after [v0.1.0a35](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a35).

## Return a finished file, not just a summary

After an approved or auto-applied native `mutate_file` action, a Work can report its exact successful file action ID to Home. The report links to its source Work and shows the current file as a real version-checked artifact. From Home, inspect the source and download the original UTF-8 bytes without leaving the conversation. The download checks the saved action, current version, and SHA-256 before handing back content. This uses the existing World, Kernel, SQLite and workspace path authority.

The report remains as history if the original action is undone or the file later changes, but no longer treats that older file version as available for preview or download. The normal file approval and Undo path is unchanged.

## Continue after long histories

A saved correction from an earlier Work now survives the pre-action-to-main-decision handoff even when the source is too old to appear in a recent shortlist. Validity checks the exact original experience, version, subject and access scope in the World-owned Posture journal. A revised, withdrawn or inaccessible source cannot silently stay active. Ordinary long-history decisions use bounded candidates and accurate omission counts rather than enumerating every older revision into the model material; explicit searches still inspect full history.

## Install or update

Requires Python 3.12+. Stop the local process and back up the complete workspace data directory before updating. Download `per_pulse-0.1.0a36-py3-none-any.whl` from this release once published.

Linux/macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a36-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a36-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example is offline; live Work requires a separately configured provider.

Publish only after exact-head PR and Push Verify, an independent merged-main Verify, the release workflow's distribution and wheel-from-sdist content checks, `SHA256SUMS`, Linux/Windows/macOS clean installations and the installed-wheel Chromium report → Home preview/download → restart → Undo path. They do not demonstrate a real model's unprompted experience transfer; that remains gated by [issue #51](https://github.com/Lightmaze/Per-Pulse/issues/51).

Do not replace an existing tag or release asset. Publish only a new `v0.1.0a36` prerelease pointing to the independently accepted merge commit.
