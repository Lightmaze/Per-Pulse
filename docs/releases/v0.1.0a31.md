# Per Pulse v0.1.0a31

Continue a source-backed Work reliably through failure, restart and later experience corrections. This release packages [#315](https://github.com/Lightmaze/Per-Pulse/pull/315), [#316](https://github.com/Lightmaze/Per-Pulse/pull/316) and [#317](https://github.com/Lightmaze/Per-Pulse/pull/317) since [v0.1.0a30](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a30).

## A Work starts with its actual task

Open a file produced in Home or another Work and choose **Start a new Work with this file**. The original producing action and SHA-256 are verified before the first task reaches the model. If the source changes during preparation or the new task is too long, creation now fails cleanly without leaving an empty Work or an orphaned material receipt. The source file and its producing Work are preserved. Repeat after correcting the source or the task.

When Home's native `work.create` admission has an uncertain outcome, the original causal idempotency key determines whether the first task committed. A committed task is recovered rather than executed twice; a confirmed unstarted Work can be removed. These paths use the existing World, Kernel and SQLite, with the original file-action approval and Undo boundaries.

## Carry a corrected experience into the next decision

Start another Work from a saved, explicitly selected experience. If its original Work later makes a substantial revision, the receiving Work sees bounded first and last source passages before its next model decision, rather than only an ID and an omission marker. The preview says it is incomplete, with the original Posture retrieval tool available for the complete current revision. Pausing or withdrawing the shared experience continues to revoke its current-use status without rewriting the historical task or artifacts.

## Install or update

Python 3.12 or later. Stop Per Pulse and back up the full workspace data directory before upgrading an existing installation. Download `per_pulse-0.1.0a31-py3-none-any.whl` from this release when published.

Linux/macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a31-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a31-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example runs without a model; normal AI work requires a configured provider.
