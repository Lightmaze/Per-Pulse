# Per Pulse v0.1.0a37

**Finish a file in one Work, come back later, and deliver that same original file to Home.** This alpha candidate packages [#357](https://github.com/Lightmaze/Per-Pulse/pull/357), [#358](https://github.com/Lightmaze/Per-Pulse/pull/358), [#359](https://github.com/Lightmaze/Per-Pulse/pull/359) and [#360](https://github.com/Lightmaze/Per-Pulse/pull/360) since [v0.1.0a36](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a36).

## A completed Work file survives the handoff

A Work can complete a file, carry on for several turns, restart its SQLite World, or resume through a committed subject succession, and later report that *original* successful file action to Home. If the earlier action ID is no longer in context, the model can use `work.report(kind="result", note="...", artifact_path="...")` with the exact Work-relative path. The original Kernel history identifies the action; no second write or separate artifact store is created.

Home preserves the producing Work and message source, verifies the action and current file version, then lets you preview and download the original bytes. Undo or a changed file invalidates the old download while preserving historical attribution. Another Work cannot claim it by guessing the same path. Existing per-file approval or auto-apply-with-Undo controls still apply.

## Keep the correction through the final review

A source-attributed correction in Work A can inform a later Work B's pre-action expert and its final deliverable review, using the same task-specific selection against the existing World/Posture journal. Older lessons are not excluded merely by newer records; source revision, ownership, withdrawal and access are rechecked. This is task-matched retrieval and review support, not a claim of autonomous model weight updates.

## Install or update

Python 3.12 or later is required. Stop Per Pulse and back up the complete World/workspace directory before updating. Once this prerelease has been published, obtain `per_pulse-0.1.0a37-py3-none-any.whl` and `SHA256SUMS` from this release.

Linux/macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a37-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a37-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example runs offline; live Work requires a separately configured provider. See [installation](../install.md) for updating and model setup.
