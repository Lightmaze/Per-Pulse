# Per Pulse v0.1.0a3

A maintenance alpha that corrects the installed release identity. This follows [v0.1.0a2](v0.1.0a2.md) without replacing its tag or files.

## Install

Requires Python 3.12 or later. Download `per_pulse-0.1.0a3-py3-none-any.whl` from this release. The browser interface is bundled; Node.js is not required.

Linux / macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a3-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a3-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The sample works without a model in separate data. Stop with Ctrl+C, then run `per-pulse` without `--example` for your own workspace. [Connect a model](../models.md) to enable AI replies.

## What changed since a2

- Runtime versions reported by `GET /api/bootstrap` and OpenAPI now match the installed `0.1.0a3` package. Published a2 misleadingly reported a1 even though it contained the correct a2 features.
- Source/package version parity is guarded by a repository regression.

The autonomous SELF start, sourced Home/Work continuity, weekly model request accounting, pause/restart and file actions from a2 remain available. The pending Habitat region extension and full upstream RIM package are not included.

## Usage boundaries

A model and its credits are not bundled. Back up your workspace before upgrades and follow [Autonomous practice](../autonomous-practice.md), [Installation](../install.md) and [Security](../../SECURITY.md). Packaging and browser tests use synthetic model decisions, not real-provider growth evidence.
