# Per Pulse v0.1.0a32

A long-running Work stays reachable and keeps its selected evidence after activity, navigation and context compaction. This release contains the merged product changes [#320](https://github.com/Lightmaze/Per-Pulse/pull/320), [#321](https://github.com/Lightmaze/Per-Pulse/pull/321) and [#322](https://github.com/Lightmaze/Per-Pulse/pull/322), plus a deterministic native Web timeout regression [#319](https://github.com/Lightmaze/Per-Pulse/pull/319), since [v0.1.0a31](https://github.com/Lightmaze/Per-Pulse/releases/tag/v0.1.0a31).

## Keep going across Works

Create multiple Works from Home and revisit an old one after newer activity. The model's native `work.list` and title `work.search` cursors now use stable creation order, so Work A will not disappear from the next page if it receives a new event between pages. Home's visible recent-activity sorting remains unchanged.

Start a Work from Home, then use Back to return to an existing draft while its creation response is still in flight. When the server acknowledgement arrives, the created Work is retained with its source, while the browser stays on the page you chose and preserves your draft and focus. Navigate to the saved Work when you are ready.

In a later Work started from an explicitly selected, shared correction or observation, the original source can be revised or withdrawn. When the native Kernel omits early conversation to fit the model context, the next decision receives the currently valid selected experience again from the same World-owned Posture journal. An oversized selection carries a bounded preview and the original `posture.get` route for full details. This never grants a file, command or network effect.

## Install or update

Python 3.12 or later. Stop the server and back up your entire workspace data directory before updating. Download `per_pulse-0.1.0a32-py3-none-any.whl` from this release when published.

Linux/macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./per_pulse-0.1.0a32-py3-none-any.whl
per-pulse --example
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\per_pulse-0.1.0a32-py3-none-any.whl
.\.venv\Scripts\per-pulse.exe --example
```

Open **http://127.0.0.1:8000**. The example runs without a provider; real model work requires one.

## Release acceptance

Require exact-head PR and Push Verify, review of the release-only diff, and reproducible wheel/sdist with Ubuntu/Windows/macOS cold installation. The installed Ubuntu wheel runs the native World/Kernel/SQLite sourced-correction → later Work → approved file → Home return → restart journey. Native CI also covers stable pagination across activity/restart, the delayed-creation Chromium journey, and real Kernel context compaction and selected-source restoration. Browser model tool choices are explicitly synthetic; live model autonomous use of experience remains a separate study under [#51](https://github.com/Lightmaze/Per-Pulse/issues/51).

Publish only after the exact merged-main Verify succeeds, with a new immutable tag and SHA256SUMS. Never overwrite v0.1.0a31.
